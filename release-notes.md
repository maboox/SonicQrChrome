# SonicQR 0.4.0 · Violet studio

A refreshed, local-first text-in-voice Chrome extension with a violet interface, English and فارسی, and clearer recording controls.

- New visual identity, dark/light themes and locally bundled Lucide icons.
- Simpler send/read flows, optional encryption settings, keyboard tabs and explicit session clearing.
- Fixed stale tab/status responses, capture setup cleanup, decoder worker failure cleanup and misleading site-compatibility state.
- Tightened internal command sender/tab checks, modulation input checks and sample-rate validation.
- Updated Playwright, regression coverage, bilingual documentation and repository security settings.

**Install:** download `sonicqr-chrome-0.4.0-webstore.zip`, extract it, then open `chrome://extensions` → Developer mode → Load unpacked. Select the folder containing `manifest.json`. Reload existing website tabs after updating.

**Beta limits:** local browser audio paths are tested; preservation after messenger compression requires testing the actual received file. High-frequency mode is experimental. No Chrome Web Store listing is claimed. The ZIP and `SHA256SUMS.txt` are attached.
